About cat

cat is a small, fast, and lightweight programming language that uses the .cat file extension. It is designed to be simple and easy to learn, while still being powerful enough for scripts and small utilities.

The cat interpreter reads .cat files and runs them directly. It is compiled to a small binary for each operating system (Linux, macOS, Windows), so you can use it without installing a heavy runtime or virtual machine.

cat language tutorial

Here are some basic examples to show you how to code with cat.

1. Variables and math

Create variables and perform basic arithmetic: 

x = 42;
y = x + 8;
print(x);  // 42
print(y);  // 50

You can use +, -, *, and / to perform math.

2. Printing text

Use print(...) to show values or text in the terminal. 

name = "Whiskers";
print("Hello, I am " + name);

3. Conditions (if/else)

Branch the flow of your program with conditions: 

age = 5;
if age > 3:
    print("Old cat.");
else:
    print("Kitten.");

4. Loops (while)

Repeat code with a while loop: 

i = 0;
while i < 3:
    print("Meow");
    i = i + 1;

Download cat

cat is available as pre‑built binaries for Linux, macOS, and Windows. You can download it from GitHub without installing any build tools.

Visit the Releases page and download the package that matches your operating system: 

https://github.com/cool-websites/cat-lang/releases/latest

After downloading:

  1. Unpack the archive (zip / tar file).
  2. Place the cat binary (or cat.exe on Windows) into a folder that is in your system’s PATH, or keep it in a chosen location.
  3. Open a terminal and run: 
    cat path/to/your/file.cat
