cat

A fast, lightweight, standalone programming language using the .cat file extension.

Example

x = 42;
y = x + 8;
print(x);  // 42
print(y);  // 50

Features

  • Standalone C binary (no runtime needed).
  • Very small executable size.
  • Simple, readable syntax for fast scripts.
